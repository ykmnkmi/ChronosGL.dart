# 3.11. VM-тесты математики камеры

Пункт **3.11** [плана рефакторинга](../REFACTORING_PLAN.md) закрепляет
проверки положения, ориентации, обратимости матриц и обоих видов проекций
на Dart VM. Существующие математические наборы 3.2–3.8 уже проверяют основные
контракты; они сохранены и дополнены четырьмя сквозными тестами.
Публичные API и реализация математики не меняются.

| [`camera_pose_test.dart`](../test/camera_pose_test.dart) | 11 | Независимость позы от чтения матриц и проекции, движение после наведения, переполнение вида, атомарность ошибок |

Итого выбранный набор содержит **83 теста**. Он использует публичные
математические импорты без браузера. Проверка самостоятельной компиляции
этих импортов относится к [3.10](3.10_VM_MATH_IMPORTS.md) и остаётся отдельным
тестом; браузерные legacy-наборы и uniforms в этот запуск не включены.

## Дополненные сценарии

Новый `camera_math_test.dart` проверяет для обоих видов камер:

- Кватернионы `q`, `-q` и их ненулевые кратные задают одну ориентацию.
  После нормализации сохраняются мировой глаз и `P * V`; известное вращение
  на 120° вокруг `(1, 1, 1)` переводит оси `X → Y`, `Y → Z`, `Z → X`.
  Ожидаемые координаты точки рассчитаны этой перестановкой осей, отдельно
  от матричной реализации камеры.
- Для перенесённой и повёрнутой камеры `V * C` и `C * V` дают единичную
  матрицу. Полная матрица `P * V` также обратима с обеих сторон.
- Решётка NDC `3 × 3 × 5` включает углы, центры и промежуточные глубины
  clip-объёма. Эталон view-координат вычисляется аналитически через параметры
  frustum или явные ортографические границы; мировые координаты — через
  известную перестановку осей и положение глаза. Проверяются проекция,
  homogeneous `w` и восстановление мира из NDC с делением на полученный `w`.
- Та же решётка проверяется после обновления проекции той же камеры без
  изменения позы. Перспективный aspect меняется с landscape на portrait;
  ортографическая проекция сначала включает знаковый `near`, а затем
  положительный диапазон глубины.

Всего проверяются 180 точек для двух камер и двух наборов параметров.
Основной абсолютный допуск — `2e-5`, для обратного перехода NDC → world —
`2e-4` из-за накопления погрешности Float32 при инверсии и делении на `w`.
Эти допуски относятся к выбранным конечным диапазонам теста и не обещают
такую же точность при произвольном отношении `far / near`.

## Запуск и результат

Быстрая проверка добавленных сценариев:

```sh
dart test -p vm test/camera_math_test.dart
```

Выбранные восемь наборов пункта 3.11:

```sh
dart test -p vm \
  test/camera_math_test.dart \
  test/camera_test.dart \
  test/camera_pose_test.dart \
  test/camera_view_matrix_test.dart \
  test/camera_look_at_test.dart \
  test/camera_matrix_access_test.dart \
  test/projection_test.dart \
  test/projection_parameters_test.dart
```

Все 83 теста прошли на Dart VM; `dart analyze test/camera_math_test.dart`
завершился без замечаний. Новый файл включён в preset `all` и сохраняет
возможность запуска в браузере, как и существующие математические наборы.
В рамках 3.11 выполнен только выбранный VM-запуск; полный preset и
браузерная матрица платформ не запускались. Пункт 3.12 остаётся отдельной
проверкой значений uniforms новой камеры в браузере.
