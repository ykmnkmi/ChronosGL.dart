# 1.1. Полный перечень публичных объявлений ChronosGL

Приложение к [карте публичного API](1.1_PUBLIC_API_MAP.md), пункт 1.1
[плана рефакторинга](../REFACTORING_PLAN.md). Снимок исходников:
`6a298e4ac64201c23ad454657772fefd5d1ada71`.

Здесь перечислены все **953 публичных объявления верхнего уровня**, доступные
через `package:chronosgl/chronosgl.dart`: 53 класса, 11 typedef, 114 функций,
660 const и 115 переменных (включая final). Члены классов относятся к владельцу;
исключения и новые сущности приведены в основной карте. Это не снимок всех
сигнатур методов и конструкторов.

Состав получен синтаксическим разбором всех экспортируемых библиотек и их
part-файлов. Приватные имена, комментарии, локальные объявления и GLSL внутри
строк исключены. Каждое текущее имя ведёт к исходной строке определения.

Колонки будущего API содержат **предложения для ревью**, а не выполненные
изменения. Модуль `*.dart` означает будущий публичный импорт
`package:chronosgl/<имя>`, `src/...` — внутреннюю реализацию, `example/...` —
код примеров. `—` означает отсутствие сущности в целевом API. Даже действие
«Сохранить имя» не гарантирует неизменность всех сигнатур и поведения;
это проверяется в соответствующей фазе. Политика переходных имён описана
в основной карте.
