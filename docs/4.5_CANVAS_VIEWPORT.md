# 4.5–4.8. Размер canvas, viewport и проекция

`CanvasViewport` из `package:chronosgl/chronosgl.dart` заменяет совместное
применение `PerspectiveResizeAware` и `RenderPhaseResizeAware` для новой камеры.
Он заимствует `ChronosGL`, `web.HTMLCanvasElement`, `Camera` и необязательный
экранный `RenderPhase`, владеет ResizeObserver и подписками изменения окна/DPR.
Размеры CSS задаёт приложение независимо от атрибутов `canvas.width/height`.

```dart
final phase = RenderPhase('main', cgl);
final viewport = CanvasViewport(cgl, canvas, camera, renderPhase: phase);
if (viewport.update()) phase.draw();
```

`update()` синхронно читает content box элемента, включая дробные CSS-пиксели,
исключает padding и border и возвращает готовность к рисованию. Размер buffer
равен `max(1, round(contentSize * pixelRatio))` для каждой положительной оси.
`pixelRatio` по умолчанию следует `window.devicePixelRatio`; явное положительное
конечное значение фиксирует плотность, а `null` возвращает автоматический режим.
Изменение DPR отслеживается отдельным media query без обязательного resize окна.
Перед рисованием рекомендуется вызывать update, чтобы синхронно учесть любые
изменения layout и плотности.

После установки атрибутов берутся фактические WebGL drawingBufferWidth/Height.
Полный viewport использует эти размеры; aspect перспективной камеры берётся из
её viewport. FOV, near/far и поза сохраняются. Явные ортографические границы не
меняются автоматически. Контекст не меняет CSS-размер элемента.

Для частичного viewport используются физические пиксели текущего buffer:

```dart
viewport.setViewport(x: 20, y: 10, width: 100, height: 200);
// aspectRatio = 0.5; начало координат снизу слева.
viewport.useFullViewport();
```

DPR не применяется к этим координатам повторно. Отрицательные размеры вызывают
`ArgumentError`; координаты не ограничиваются границами buffer. Offscreen
framebuffer и его attachments обслуживаются отдельно; переданный renderPhase
должен рисовать на экран.

При скрытом/нулевом canvas update возвращает false, устанавливает пустой viewport
и сохраняет последнюю корректную проекцию. `RenderPhase.draw()` с нулевой шириной
или высотой пропускает активацию framebuffer, clear и обход сцены. Отрицательные
размеры прохода — ошибка. При восстановлении элемента следующий update снова
согласует buffer, viewport и aspect без пересоздания компонента.

`disable()` отключает ResizeObserver, window resize и media query; update
отключённого компонента возвращает false. `enable()` подключает их заново и сразу
синхронизирует размер. `dispose()` повторно безопасен и окончательно отключает
наблюдение; update, enable и изменение настроек после него дают `StateError`.
Поздние callbacks старого подключения игнорируются. Заимствованные объекты
остаются пригодны для использования.

[Браузерные проверки](../test/canvas_viewport_test.dart) покрывают размеры,
плотность, viewport, скрытие и жизненный цикл. Старые resize helpers сохранены
для миграции с прежним поведением.
