# 4.1–4.4. Управление отдельной камерой

`OrbitControls` из `package:chronosgl/chronosgl.dart` управляет переданной
математической `Camera`, не наследуется от неё и не меняет проекцию. Камера и
явный `web.EventTarget` заимствованы; контроллер владеет своими DOM-обработчиками.
Математические импорты `camera.dart` и `core.dart` не получают DOM-зависимостей.

```dart
final camera = PerspectiveCamera(near: 0.1, far: 1000);
canvas.tabIndex = 0;
canvas.focus();
final controls = OrbitControls(camera, canvas, radius: 15);
controls.update(deltaSeconds);
```

Настоящие клавиатурные события получает сфокусированный target. Контроллер
не подставляет `document` вместо canvas. `target` — мировая точка наблюдения:
конструктор и setter копируют вектор, getter возвращает снимок. Радиус положителен,
`azimuth` и `polar` заданы в радианах. Нулевой азимут ставит глаз на +X;
положительный азимут направлен к +Z, polar — высота над XZ. Полярный угол
ограничивается диапазоном `[-pi/2 + 0.1, pi/2 - 0.1]`.
Настройки применяются при `update`, включая первый нулевой шаг.

| Ввод / настройка | Единица и применение |
| --- | --- |
| Стрелки, `rotationSpeed` | Радиан/секунду, по умолчанию 1.8 |
| PageUp / PageDown, `zoomSpeed` | Изменение логарифма радиуса в секунду, по умолчанию 0.6 |
| Левая / средняя кнопка, `dragRadiansPerPixel` | Радиан/CSS-пиксель, по умолчанию 0.01 |
| Колесо, `wheelZoomPerUnit` | Изменение логарифма радиуса на нормализованный CSS-пиксель, по умолчанию 0.002 |
| `wheelLineHeightCssPixels` | CSS-пикселей на строку колеса, по умолчанию 16 |

Противоположные удерживаемые клавиши взаимно компенсируются. Зум использует
`radius *= exp(rate * deltaSeconds)`: равное суммарное время даёт равный радиус.
Space сбрасывает углы при положительном шаге. Отрицательный или неконечный
`deltaSeconds` отклоняется через `ArgumentError` до изменения камеры.

Движение мыши суммируется из разностей CSS-координат только во время drag;
колесо суммируется отдельно. Pixel mode использует delta непосредственно,
line mode — явный размер строки, page mode — высоту target (или окна).
DPR не умножает ввод. Mouseup сохраняет уже накопленное перемещение.
Каждый успешный `update` потребляет дельты один раз; время не умножает их.
Нулевой шаг обрабатывает накопленные события без движения удерживаемых клавиш.
Без нового ввода следующий шаг сохраняет позу.

`disable()` синхронно снимает обработчики и очищает клавиши, кнопки и дельты.
`enable()` повторно подключает их без воспроизведения старого ввода; операции
повторно безопасны. Blur очищает ввод. Нулевой размер элемента блокирует ввод
и обновление позы. `await dispose()` окончательно отключает компонент; повторный
вызов возвращает тот же Future. Поздние callbacks старого подключения игнорируются.
После dispose обновление, включение и изменение настроек выбрасывают `StateError`;
чтение диагностического состояния и повторный disable остаются допустимыми.
Освобождение контроллера не освобождает камеру или target.

`OrbitCamera` сохранён для миграции с прежними единицами и поведением.
