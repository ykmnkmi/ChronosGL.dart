# 6.11. Границы бывшего misc, независимые настройки и проверки фазы 6

Фаза 6 разделяет поддерживаемые возможности движка, необязательную диагностику
и код примеров. Общий импорт `chronosgl.dart` сохраняет поддерживаемые сущности;
`src/misc/lib.dart` оставлен только как переходный набор экспортов.
Пути миграции описаны в [MIGRATION.md](../MIGRATION.md#helpers-and-settings-refactoring-phase-6).

## Назначение модулей и владение

| Задачи | Модуль | Контракт |
| --- | --- | --- |
| 6.1, 6.10 | `example/shared/particles.dart`, `shaders.dart` | Демонстрационные звёзды, спрайты и фиксированные шейдеры; случайный генератор передаётся явно, созданные меши и текстуры освобождает пример |
| 6.2, 6.3 | `mesh.dart`, `src/mesh/shape_factories.dart` | Документированные GPU-фабрики `shape*`; меш принадлежит вызывающему коду, программа заимствуется, все параметры геометрии передаются дальше |
| 6.4 | `src/scene/fullscreen_pass.dart` | `FullscreenPass` владеет quad и создаёт независимый материал; переданный материал и его текстуры заимствуются, владение программой включается через `ownsProgram: true` |
| 6.5, 6.6 | `shadows.dart`, `src/shadows/shadow_map.dart` | `ShadowMap` владеет вычислительной программой, framebuffer и attachments; узлы и их ресурсы заимствуются, диагностика не создаётся |
| 6.6–6.8 | `debug.dart`, `src/diagnostics/` | Визуализатор теней создаёт программу, quad и sampler при первом draw; визуализаторы света и костей — свой меш при первом чтении `mesh`; `dispose()` освобождает только собственные ресурсы |
| 6.8 | `StatsPanel`, `FpsPanel` | Панель владеет оформленной DOM-обёрткой, сохраняет чужие стили и соседние элементы; старые `Stats`/`StatsFps` остаются aliases |
| 6.9 | `core.dart`, настройки материалов и текстур | Неизменяемые `Color`, `TextureProperties`, blend/stencil values и presets; варианты создаются через конструктор или `copyWith()`, векторы цветов — явно через `toVector3()` |
| 6.10 | `src/webhelper/resize_aware.dart` | Legacy resize-помощники относятся к браузерной интеграции, владеют отключаемыми подписками, заимствуют остальные ресурсы |

CPU-генераторы остаются в `geometry.dart` без браузерных зависимостей.
`shapeCube(computeNormals: false)` больше не добавляет нормали. Добавлены
пропущенные параметры `shapeWedge.computeNormals`, `shapeTorusKnot.wrap`,
`computeUVs`, `inside`; `shapeQuad` принимает дробный размер. Прежние позиции
параметров сохранены для миграции, а документация явно различает радиусы,
полуразмеры, полную длину и число подразделений.

`emptyMaterial` удалён; переходный `unitNode` создаёт независимые материалы.
`FullscreenPass` удерживает собственный меш отдельно от изменяемой ссылки узла:
подмена `node.mesh` не передаёт владельцу новый меш и не теряет исходный.
То же правило соблюдается визуализаторами света и костей. Материал не является
владельцем переданных текстур; его использование не переносит владение ими.

`ShadowMapVisualizer` использует отдельный sampler без изменения сравнения и
фильтров depth texture. На успехе и ошибке восстанавливаются прежние sampler,
2D binding нулевого texture unit и активный unit. Остальное состояние соответствует
обычному fullscreen draw. Перед новым вычислением карта теней включает depth
write mask: очистка после визуализации не оставляет глубину предыдущего кадра.
Визуализатор освобождается до заимствованной карты теней.

Создание и удаление частичных ресурсов проверены отдельно, включая ошибки самой
очистки, повторный `dispose()` и повторную ленивую инициализацию после ошибки.
После удаления операции использования дают `StateError`; диагностические
свойства и независимый `getMapSize()` остаются доступны.

## Выбранные проверки

| Набор | Результат и проверяемый контракт |
| --- | --- |
| `phase6_boundaries_test.dart` | 3 на VM: `Color` и адаптеры, отсутствие импортов примеров во всех `lib`-источниках, отсутствие транзитивной зависимости теней от диагностики, webhelper и misc |
| `math_imports_test.dart` | 1 на VM: отдельная компиляция и запуск публичных математических импортов |
| `mesh_factories_test.dart` | 15 в JavaScript: размеры, UV, нормали, индексы, winding, seam-параметры и независимые seeded звёзды |
| `shared_settings_reproduction_test.dart` | 7 в JavaScript: варианты цветов, blending, stencil function/op, texture settings с WebGL readback и независимые материалы `unitNode` |
| `fullscreen_pass_test.dart` | 6 в JavaScript: заполнение viewport с чтением пикселей, ошибки uniforms, уникальные материалы, заимствованные ресурсы, подмена ссылок узла и очистка при ошибках |
| `shadow_diagnostics_test.dart` | 16 в JavaScript: отсутствие неиспользуемых GPU-ресурсов, ленивое создание и retry, освобождение, заимствованные casters, восстановление sampler и глубины, владение DOM, фактический интервал FPS |
| `resize_aware_disposal_test.dart` | 1 в JavaScript: повторное отключение resize без изменения заимствованных ресурсов и без обработки следующих событий |
| Выбранные случаи `webhelper_interop_test.dart`, `legacy_dom_compatibility_test.dart` | Проходят: новая обёртка панелей, aliases, legacy DOM, resize и перенесённая particle canvas |
| Выбранные случаи texture constructor/disposal | 4 в JavaScript: частичная загрузка mutable/image/cube и сохранение заимствованных DOM-источников после удаления |
| `render_golden_test.dart`, только geometry/depth/blending/lighting | 4 в JavaScript: совпадение с существующими reference PNG без обновления эталонов |
| `shadow_diagnostics_test.dart`, только sampling state/FPS panels | 3 в Wasm: новые sampler bindings, восстановление при ошибке, сравнение native JS handles и владение DOM |

Все перечисленные проверки прошли; целевой анализ изменённых модулей,
потребителей и тестов завершился без замечаний. Новые suites добавлены в preset
`all`, который в этой фазе не запускался. Проверки выполнялись отдельно по
областям, повторные запуски выбирали только изменённые случаи.

Основные целевые команды для повторения (при необходимости задать
`CHROME_EXECUTABLE=/usr/bin/chromium`):

```sh
dart test -p vm test/phase6_boundaries_test.dart test/math_imports_test.dart
dart test -p golden_chrome test/mesh_factories_test.dart test/shared_settings_reproduction_test.dart --concurrency 1
dart test -p golden_chrome test/fullscreen_pass_test.dart test/resize_aware_disposal_test.dart --concurrency 1
dart test -p golden_chrome test/shadow_diagnostics_test.dart
dart test -p golden_chrome test/webhelper_interop_test.dart test/legacy_dom_compatibility_test.dart --name 'Stats|Resize helpers|Canvas helpers|legacy DOM' --concurrency 1
dart test -p golden_chrome test/resource_creation_failure_test.dart test/gpu_resource_disposal_test.dart --name 'texture constructor|Image texture disposal' --concurrency 1
dart test -p golden_chrome test/render_golden_test.dart --name 'golden (geometry|depth|blending|lighting)$' --concurrency 1
dart test -p golden_chrome -c dart2wasm test/shadow_diagnostics_test.dart --name 'sampling state|FPS panels'
```

Полный анализ, сборка всех примеров, полная матрица платформ и выпускная проверка
остаются задачами фазы 8. Разграничение всего публичного API остаётся фазой 7.
