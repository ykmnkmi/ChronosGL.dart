# 5.8. GPU-меш и совместимость раскладки

`GpuMesh` — GPU-ресурс с VAO и буферами. Прежнее имя `MeshData` сохранено
как alias, `RenderProgram.makeMeshData` — как обёртка `makeGpuMesh`.
Владение буферами, повторно безопасное освобождение, замена буферов и запрет
операций после `dispose()` сохраняют контракты фазы 2.

`RenderProgram.attributeLayout` и `GpuMesh.attributeLayout` имеют тип
`MeshAttributeLayout`. Это неизменяемая map canonical names к
`VertexAttributeLayout`: `location`, GLSL `type`, компонентная `width` и
instancing `divisor`. Обычные атрибуты имеют divisor 0, `ia*` — 1.
Отрицательные и повторные locations, неподдерживаемые типы и массивы
атрибутов отклоняются до создания GPU-ресурса.
Целочисленные атрибуты загружаются в 32-битные integer buffers и связываются
через `vertexAttribIPointer`, сохраняя целочисленную семантику GLSL.

Раскладка фиксируется при создании программы или прямом создании меша;
`makeGpuMesh` использует снимок программы. Изменения shader builder
и его map после создания не меняют существующие bindings. Это позволяет
проверять реальную совместимость скомпилированного набора атрибутов.

```dart
final mesh = uploadGeometry('cube', firstProgram, cubeGeometry());
if (mesh.isCompatibleWith(secondProgram)) {
  secondProgram.draw(mesh, uniforms);
}
```

Совместимость требует того же объекта `ChronosGL` и совпадения имени,
location, типа, width и divisor каждого атрибута, требуемого программой.
Дополнительные bindings меша разрешены. `MeshAttributeLayout.supplies`
проверяет только раскладки; `mesh.isCompatibleWith(program)` также учитывает
контекст. Predicate не проверяет заполнение буферов или жизненный цикл.

`program.hasCompatibleAttributesTo(other)` требует равенства раскладок
и контекста; `hasDownwardCompatibleAttributesTo(other)` проверяет, что меш
для `other` можно передать в текущую программу. `draw` отклоняет несовместимый
меш через `ArgumentError` до чтения групп uniforms и изменения WebGL-состояния.
Совместимый меш можно использовать в нескольких программах без передачи
владения; их освобождение не освобождает меш.
