# 5.9. Проверки сцены, CPU-геометрии и GPU-раскладок

Фаза 5 проверена выбранными наборами. Новые suites включены в preset `all`;
полный preset и полная матрица платформ в этой фазе не запускались.

| Набор | Проверяемый контракт | Результат |
| --- | --- | --- |
| `geometry_vm_test.dart` | VM-импорты генераторов и polygon, размеры и winding grid, copy/ownership, merge, runtime validation, отсутствие нормалей при выключенном флаге | 15 на VM |
| `math_imports_test.dart` | Компиляция и запуск отдельной VM-программы с прежними `core.dart` и `camera.dart` | 1 на VM |
| `scene_model_test.dart` | Различимые типы узлов, вложенные/world normal transforms, DAG и независимость матриц, preorder, порядок batch/pass, clear/readback, disabled/empty viewport, коллекции и ошибки | 8 в JavaScript |
| `mesh_layout_test.dart` | Неизменяемая раскладка, неверные locations, снимок shader metadata, совместимые программы и subset layouts, разные контексты, общий registry, integer readback, divisors, независимость CPU/GPU, ранняя валидация и очистка ошибок upload | 14 в JavaScript |
| `scene_uniforms_test.dart`, `transform_compatibility_test.dart` | Прежние контракты списков uniforms, исключений, const-списков и явного моста `Transform` → `Node` | 9 в JavaScript |
| `scene_lifecycle_test.dart`, `mesh_data_disposal_test.dart`, `resource_replacement_test.dart`, `disposed_usage_test.dart`, `grid_geometry_test.dart` | Общие ресурсы и DAG, циклы создания/удаления, повторное освобождение, замена/откат GPU-буферов, disposed-зависимости и размеры сетки | 82 в JavaScript |
| `render_golden_test.dart`, только geometry/depth/blending/lighting | Обход сцены, формы, normal matrix, depth и blending относительно существующих эталонов | 4 в JavaScript |
| `mesh_layout_test.dart`, только integer и instancing | Новая целочисленная WebGL interop-ветвь, integer lists и instancing divisors | 2 в Wasm |

Целевые команды для повторения; Chromium задаётся через
`CHROME_EXECUTABLE=/usr/bin/chromium`, если Chrome не обнаруживается автоматически:

```sh
dart test -p vm test/geometry_vm_test.dart test/math_imports_test.dart
dart test -p golden_chrome test/scene_model_test.dart test/mesh_layout_test.dart --concurrency 1
dart test -p golden_chrome test/scene_uniforms_test.dart test/transform_compatibility_test.dart --concurrency 1
dart test -p golden_chrome test/scene_lifecycle_test.dart test/mesh_data_disposal_test.dart test/resource_replacement_test.dart test/disposed_usage_test.dart test/grid_geometry_test.dart --concurrency 1
dart test -p golden_chrome test/render_golden_test.dart --name 'golden (geometry|depth|blending|lighting)$' --concurrency 1
dart test -p golden_chrome -c dart2wasm test/mesh_layout_test.dart --name 'CPU and GPU imports|Instance layouts' --concurrency 1
```

Эталоны изображений не обновлялись: все четыре выбранные сцены совпали
с существующими reference PNG. Целевой анализ изменённых библиотек, интеграции
с canvas и тестов завершился без замечаний. Сборка всех примеров, полный анализ
и выпускная матрица остаются задачами фазы 8.

Критерии фазы 5 выполнены: CPU-геометрия создаётся и проверяется без браузера;
контейнеры не имеют падающих resource getters; DAG сохраняет порядок и
преобразование каждого пути; ошибки не оставляют повреждённого состояния обхода.
Совместимость GPU-меша с программой проверяется явно до начала draw.
