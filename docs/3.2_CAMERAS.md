# 3.2. Общий контракт Camera и две проекции

Пункт **3.2** [плана рефакторинга](../REFACTORING_PLAN.md) вводит
`Camera`, `PerspectiveCamera` и `OrthographicCamera`. Публичный импорт
`package:chronosgl/camera.dart` работает на VM, JavaScript и Wasm;
те же типы доступны через общий браузерный импорт `chronosgl.dart`.
Модуль зависит только от математических компонентов и `vector_math`.
В [пункте 3.3](3.3_PROJECTIONS.md) расчёт проекций выделен в отдельные
неизменяемые значения; существующий API камер сохранён.

## Общий контракт

`Camera` — абстрактный класс с общей реализацией мировой позы и матрицы вида.
Подкласс предоставляет `projectionMatrix` как независимый снимок. Обе готовые
камеры используют этот контракт и отличаются параметрами проекции.

Поза принадлежит камере и содержит только перенос и вращение. Начиная с
[пункта 3.4](3.4_CAMERA_POSE.md), положение и ориентация хранятся отдельно,
а матрицы вычисляются из этих компонентов с единичным масштабом.
Конструкторы принимают необязательные `position` и `rotation`; по умолчанию
камера находится в начале координат и смотрит вдоль `−Z`, вверх — `+Y`.
Переданные объекты копируются, ненулевой кватернион нормализуется.
Привязки к родителю, импорта произвольной матрицы и масштаба в API 3.2 нет.

| API | Смысл |
| --- | --- |
| `worldPosition`, `worldRotation` | Снимки положения глаза и ориентации в мировом пространстве |
| `worldMatrix` | `C`: camera-local → world, жёсткое преобразование |
| `viewMatrix` | `V = inverse(C)`: world → view |
| `projectionMatrix` | `P`: view → clip |
| `viewProjectionMatrix` | `P * V`: world → clip |
| `setPosition(x, y, z)`, `setPositionFromVector(v)` | Мировое положение, ориентация сохраняется |
| `setRotation(q)` | Нормализованная мировая ориентация, положение сохраняется |
| `lookAt(target, upHint: ...)` | Наведение локальной оси `−Z` на мировую цель, положение сохраняется |

`upHint` — мировое направление, по умолчанию `+Y`. Ограничения `lookAt`
совпадают с `Transform`: конечные компоненты, несовпадающие глаз и цель,
ненулевой up и синус угла между направлениями больше `1e-6`.
Неверный аргумент даёт `ArgumentError` без изменения позы.

Все изменения видны немедленно; `update()` не требуется. Каждый getter
вектора, кватерниона или матрицы возвращает независимый снимок: правка
результата не меняет камеру, а последующая правка камеры не меняет старый снимок.
Матрица вида не записывается в состояние позы. Если вычисленный `V` или `P * V`
не представим конечными значениями Float32, чтение даёт `StateError`.
Камера не владеет GPU-ресурсами или подписками; `dispose()` не нужен.

## Параметры проекций

`PerspectiveCamera` требует именованные `near` и `far`. Необязательные
`fovYRadians` и `aspectRatio` по умолчанию равны `50 * pi / 180` и `1`.
FOV — полный вертикальный угол в радианах, aspect — ширина / высота.
Требуются `0 < fovYRadians < pi`, `aspectRatio > 0`, `0 < near < far`.

`OrthographicCamera` требует явные `left`, `right`, `bottom`, `top`, `near`,
`far` в единицах сцены. Требуются `left < right`, `bottom < top`, `near < far`.
Нулевой и отрицательный `near` допустимы, в том числе для объёмов теней.
Границы не зависят от canvas и не пересчитываются неявно по aspect.

Обе камеры имеют `setProjection(...)` со всеми обязательными параметрами
соответствующей проекции. Операция атомарно заменяет параметры и матрицу,
сохраняя позу. Для изменения одного параметра остальные передаются через
getters. Все параметры должны быть конечными, полученная Float32-матрица —
конечной и невырожденной; нарушение даёт `ArgumentError` до записи состояния.
Бесконечная дальняя плоскость и reversed-Z не поддерживаются.
Плоскости `zView = -near` и `zView = -far` переходят в NDC `−1` и `+1`.

```dart
import 'dart:math' as math;
import 'package:chronosgl/camera.dart';
import 'package:vector_math/vector_math.dart' as vm;

final camera = PerspectiveCamera(
  fovYRadians: 50 * math.pi / 180,
  aspectRatio: 16 / 9,
  near: 0.1,
  far: 1000,
)..setPosition(0, 0, 10);
camera.lookAt(vm.Vector3.zero());
// camera.worldPosition остаётся (0, 0, 10).
final worldToClip = camera.viewProjectionMatrix;

camera.setProjection(
  fovYRadians: camera.fovYRadians,
  aspectRatio: 4 / 3,
  near: camera.near,
  far: camera.far,
);
```

## Границы перехода

`Spatial`, `Perspective`, `Orthographic` и `OrbitCamera` сохраняют прежний API
и поведение. Новые камеры не являются их aliases или подклассами и не являются
`UniformGroup`. Передавать новую камеру вместо `Spatial` в старую `Perspective`
или непосредственно в список uniforms нельзя. Для перехода используется
новая мировая поза; перенос старой view-матрицы как позы неверен.

Пункт 3.2 включает рабочий математический минимум общего контракта, в том числе
вычисление вида, наведение, снимки и проверки аргументов. Остальные пункты
фазы 3 не отмечаются завершёнными: отдельные переиспользуемые `Projection`
для камер и теней относятся к 3.3, дальнейшее уточнение состояния и доступа
к матрицам — к 3.4–3.8, `CameraUniforms` — к 3.9, итоговые проверки границ
импортов, математики и браузерных uniforms — к 3.10–3.12.
Контроллеры и resize относятся к фазе 4. Старые воспроизведения ошибки
позиции камеры продолжают фиксировать legacy-поведение.

## Проверки

[`camera_test.dart`](../test/camera_test.dart) содержит 25 математических тестов:
общая поза обеих камер, обратимость матриц, сохранение позиции при наведении,
мировой up, копирование состояния, границы frustum, вертикальный FOV и aspect,
асимметричная ортографическая проекция, нулевые/отрицательные clipping distances
и атомарное отклонение неверных параметров.
[`camera_compatibility_test.dart`](../test/camera_compatibility_test.dart)
проверяет идентичность публичных экспортов в браузере.
Оба файла включены в preset `all`.

```sh
dart analyze
dart test test/camera_test.dart
dart test -P all
dart test -P all -p golden_chrome -c dart2wasm
```

Результаты на Dart 3.14.0: `dart analyze` — без замечаний; отдельный VM-набор —
25 тестов; полный VM/JavaScript-прогон — 366 тестов; прогон с Wasm — 364 теста
(preset также выполняет VM-наборы; два legacy DOM-теста предназначены только
для JavaScript). Все 25 математических тестов новой камеры проходят на трёх
платформах; проверка экспортов — на JavaScript и Wasm. Rendering goldens
совпадают с существующими эталонами; изображения не обновлялись.
