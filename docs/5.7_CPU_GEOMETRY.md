# 5.7. Граница CPU-геометрии и GPU-ресурсов

`package:chronosgl/geometry.dart` доступен на Dart VM и экспортирует
`GeometryBuilder`, грани, генераторы форм, polygon-алгоритмы и метаданные
вершинных атрибутов. В его графе импортов нет DOM, WebGL и `dart:js_interop`.
Математические точки входа `core.dart` и `camera.dart` сохраняют прежнюю границу.

```dart
import 'package:chronosgl/geometry.dart';

void main() {
  final geometry = gridGeometry(2, 3, 8, 6)..validate();
  print(geometry.generateFaceIndices().length); // 36
}
```

Builder и `ShaderObject` стали самостоятельными CPU-библиотеками. Браузерный
core импортирует и экспортирует те же объявления; отдельной копии registry
атрибутов нет. Пользовательские атрибуты регистрируются прежними
`introduceNewShaderVar` и `ShaderVarDesc`, в том числе без браузера.

`GeometryBuilder` остаётся изменяемым редактором. `validate()` и совместимый
`sanityCheck()` проверяют конечность координат, границы каждого индекса,
отсутствие граней в point cloud, известный тип атрибутов, число значений
на вершину и корректность значений. Нарушение даёт `StateError` на VM
и в браузере, независимо от assert. Неизвестное имя в прямом вызове
`retrieveShaderVarDesc` даёт `ArgumentError`. Пустая геометрия допустима.

Обычные добавления векторов копируют значения. Варианты `TakeOwnership`
передают элементы, но не исходный контейнер списка. Merge переносит содержимое,
смещает индексы и оставляет источник пустым, пригодным к повторному использованию.
Несовместимые point/face modes, атрибуты и self-merge отклоняются до переноса
и применения преобразования к источнику.

`uploadGeometry(name, program, geometry)` и `uploadWireframeGeometry(...)`
относятся к браузерному слою. Они проверяют builder до создания VAO,
формируют отдельные числовые массивы и возвращают принадлежащий вызывающему
`GpuMesh`. Изменение CPU-builder после загрузки не меняет GPU-меш;
освобождение меша не очищает builder. Ошибка загрузки освобождает частично
созданный меш, сохраняя исходное исключение. Прежние upload helpers сохранены
как обёртки.

Генератор `wedgeGeometry(computeNormals: false)` не создаёт пустой атрибут
нормалей: результат проходит CPU-проверку и пригоден для position-only загрузки.
Демонстрационные GPU-фабрики `shape*` остаются в прежнем модуле до фазы 6.
