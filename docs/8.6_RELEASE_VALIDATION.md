## Исправления, выявленные проверками выпуска

Усиленный контракт `GpuMesh.changeVertexData` требует прежнего числа вершин.
Визуализатор света создавал placeholder из одной вершины и пытался через этот
метод загрузить полноценный wireframe. Исправление использует `addVertices`
при изменении размера и сохраняет `changeVertexData` для обновлений того же
размера. Изменение количества частиц в примере transform feedback аналогично
заменяет storage CPU-меша и обоих GPU-мешей.

Проверки охватывают четыре прямых updater-функции, смену point/directional/spot
на одном `LightVisualizer`, корректные индексы, действительную отрисовку,
повторное использование буферов и баланс освобождения ресурсов. Ранее
падавший lazy-тест также проходит. Выборочный повтор:

```sh
dart test -p golden_chrome test/shadow_diagnostics_test.dart --name 'Light wireframe|LightVisualizer changes topology|Diagnostic wireframe is lazy'
```

Результат: 7 тестов проходят. После исправления пройдены итоговые полные наборы
из таблицы выше.

Release-компиляция `tunnel_vision` также выявила недопустимый tear-off внешнего
interop-метода `musicElement.pause`. Callback очистки заменён на Dart-замыкание
`() => musicElement.pause()`. Выборочная проверка проходит, затем успешно
повторена полная команда сборки галереи:

```sh
dart compile js -O4 -o build/phase8_validation/tunnel_vision.js example/tunnel_vision/tunnel_vision.dart
```

## Изображения и самопроверка

Эталонные PNG не обновлялись. Просмотрены все семь изображений из
`test/goldens/`: композиция цветных фигур (`geometry`), перспектива и
ортографическая проекция, клетчатая текстура, порядок перекрытия по глубине,
смешивание и освещённые сфера с кубом. Миграция тестовых сцен сохраняет их
положение, проекции, цвета и порядок отрисовки; исправление диагностического
wireframe не меняет эти сцены.

JavaScript и Wasm сравнивают рендер с теми же сохранёнными PNG и прежним
допуском. Самопроверка намеренно меняет цвет геометрии, должна получить
несовпадение и записать expected/actual/diff, затем подтвердить обнаружение
регрессии. Это ожидаемое падение внутреннего теста самопроверки, а не ошибка
выпуска и не обновление эталона.
Просмотр expected/actual/diff подтверждает замену красного куба зелёным;
обнаружены 8513 отличающихся пикселей при максимальной разнице канала 255.
SHA-256 всех семи эталонов после самопроверки совпадают со значениями до неё.
Обычные JavaScript- и Wasm-прогоны проходят с этими неизменёнными изображениями.

## CI и границы проверки

[Workflow](../.github/workflows/tests.yml) устанавливает зависимости с
`--enforce-lockfile`, выполняет полный анализ, VM/JavaScript, Wasm и
самопроверку golden. Preset `all` включает CPU-импорты, публичные browser
импорты, новые проверки времени жизни примеров и освобождения golden-сцен.
Отдельная job `examples` собирает всю галерею в release. При ошибке браузерных
тестов workflow сохраняет изображения сравнения. Настройка доступа Windows
sandbox к закреплённому Chrome for Testing сохранена.

В этой сессии проверены конфигурация CI и эквивалентные локальные команды;
удалённый workflow не запускался. Доступ к реальной камере и MIDI-устройствам
вручную не проверялся: сборка подтверждает их компиляцию, браузерные тесты —
контракты соответствующих помощников и очистки. Эти проверки не выполняют
публикацию пакета.
