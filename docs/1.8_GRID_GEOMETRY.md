# 1.8. Индексация и независимые размеры gridGeometry

Исправление выполнено в [генераторе сетки](../lib/src/shape/plane.dart).
[Регрессионные тесты](../test/grid_geometry_test.dart) включены в preset `all`.

## Причины ошибок

Вершины заполняются по столбцам: для каждого X перебираются все значения Y.
Поэтому шаг индекса между столбцами равен `ystrips + 1`. Ранее использовалось
`xstrips + 1`: при `xstrips > ystrips` происходил выход за границы списка,
а при `xstrips < ystrips` часть вершин перезаписывалась и часть оставалась
нулевой. Та же ошибочная индексация использовалась при построении граней.

Шаг координаты Y вычислялся как `xlen / ystrips`. Из-за этого высота зависела
от ширины, а сетка при разных длинах сторон смещалась относительно начала
координат. Теперь шаг равен `ylen / ystrips`.

## Контракт и воспроизведение

Для положительных чисел подразделений и размеров:

- `xstrips` и `ystrips` задают число ячеек по X и Y.
- `xlen` и `ylen` задают полные, независимые размеры сторон.
- Сетка лежит в плоскости XY: X от `-xlen / 2` до `xlen / 2`,
  Y от `-ylen / 2` до `ylen / 2`, Z равен нулю.
- Число вершин — `(xstrips + 1) * (ystrips + 1)`, четырёхугольных ячеек —
  `xstrips * ystrips`; каждая ячейка превращается в два треугольника.
- UV покрывают `[0, 1]` по каждой оси. Нормали и лицевая сторона направлены по +Z.

Минимальный вызов через публичный импорт:

```dart
import 'package:chronosgl/chronosgl.dart';

void main() {
  final grid = gridGeometry(3, 2, 8.0, 3.0);
  assert(grid.vertices.length == 12);
  assert(grid.faces4.length == 6);
  assert(grid.generateFaceIndices().length == 36);
}
```

До исправления этот вызов завершался `RangeError`. После исправления он создаёт
сетку шириной 8 и высотой 3 с центром в начале координат.
Вызов `gridGeometry(2, 3, 6.0, 6.0)` отдельно воспроизводит повреждение вершин,
а `gridGeometry(2, 2, 8.0, 3.0)` — неверный размер по Y.

Сигнатура функции и порядок вершин квадратных сеток сохранены. `shapeGrid`
передаёт параметры этому генератору и получает исправление автоматически.

## Регрессионные проверки

Одиннадцать сценариев охватывают квадратную сетку, разные размеры при одинаковом
числе подразделений, оба соотношения `xstrips` и `ystrips`, одну ячейку вдоль
каждой оси и дробные размеры. Проверяются:

- Полная решётка без повторных или незаполненных вершин, центрирование,
  соответствие координат и UV, нормали.
- Число граней, допустимость индексов, использование всех вершин
  и покрытие каждой ячейки ровно один раз.
- Размеры ячеек, ненулевая площадь и ориентация результирующих треугольников.

Проверки не зависят от порядка хранения вершин и не создают WebGL-контекст.
Они запускаются в браузере, поскольку текущий импорт геометрии зависит от
браузерного core; отделение CPU-геометрии запланировано в фазе 5.

## Запуск

Из корня проекта с установленными зависимостями и Chrome:

```sh
dart test -p golden_chrome test/grid_geometry_test.dart
dart test -p golden_chrome -c dart2wasm test/grid_geometry_test.dart
```

Полные проверки, включающие новые сценарии:

```sh
dart analyze
dart test -P all
dart test -P all -p golden_chrome -c dart2wasm
```

На исходном коде с JavaScript-компиляцией десять сценариев воспроизвели ошибки;
контрольная квадратная сетка с равными сторонами прошла.
После исправления все одиннадцать сценариев прошли в JavaScript и Wasm.
Статический анализ завершился без замечаний; полные наборы прошли:
78 тестов VM/JavaScript и 76 тестов VM/Wasm, включая сравнение изображений
с эталонами.
