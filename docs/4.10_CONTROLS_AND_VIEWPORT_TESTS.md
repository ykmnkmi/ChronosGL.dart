# 4.10. Проверки управления и размера canvas

Фаза 4 проверяется выбранными наборами через публичный импорт
`package:chronosgl/chronosgl.dart`; математическая траектория примера и граница
импортов проверяются на Dart VM. Все новые файлы тестов включены в preset `all`,
но для работы над фазой достаточно целевых запусков ниже.

| Файл | Проверяемое поведение |
| --- | --- |
| `orbit_controls_test.dart` | Обе камеры, копирование target, изоляция событий, накопление/одноразовое потребление drag и wheel, единицы колеса, отключение, blur, нулевой размер, повторное освобождение, старые callbacks и ошибки |
| `orbit_frame_rate_reproduction_test.dart` | Обе оси и оба направления, зум, 30/60/120 FPS и неравномерные шаги, нулевой шаг, прекращение движения после keyup |
| `canvas_viewport_test.dart` | CSS content box, дробные размеры, DPR, ResizeObserver без resize окна, скрытие/восстановление, partial viewport, фактический buffer, фиксированная ортографическая проекция и очистка наблюдателей |
| `camera_controls_integration_test.dart` | Одна камера в controls, viewport, CameraUniforms и Scene; чтение загруженных uniforms из WebGL после управления и resize, скрытие/восстановление |
| `torus_knot_controls_test.dart` | Начальная поза и радиальный up, равное время при разных шагах, обе проекции и отклонение неверных интервалов |
| `math_imports_test.dart` | Компиляция и запуск отдельной VM-программы с `core.dart` и `camera.dart` без DOM |

```sh
dart test -p vm test/torus_knot_controls_test.dart test/math_imports_test.dart
dart test -p golden_chrome test/orbit_controls_test.dart test/orbit_frame_rate_reproduction_test.dart test/canvas_viewport_test.dart test/camera_controls_integration_test.dart --concurrency 1
dart test -p golden_chrome -c dart2wasm test/orbit_controls_test.dart test/orbit_frame_rate_reproduction_test.dart test/canvas_viewport_test.dart test/camera_controls_integration_test.dart --concurrency 1
```

Если Chrome не обнаружен, задать `CHROME_EXECUTABLE`; в текущем окружении
использован `/usr/bin/chromium`. Проверки JavaScript выполнялись выбранными
группами: 15 проверок ввода, семь проверок времени, 12 проверок resize и одна
сквозная проверка. Все 35 прошли и в JavaScript, и в одном выбранном запуске
Wasm. Четыре теста траектории и одна проверка импортов прошли на VM.
Целевой анализ изменённых компонентов, примеров и тестов завершился без замечаний.
Эталоны изображений не менялись;
полная матрица платформ и сборка всех примеров относятся к фазе 8.

Совместная проверка завершает контрольную точку после фазы 4: новая камера,
контроллер ввода и resize работают вместе, а математические импорты остаются
пригодны для VM. Старые воспроизведения управления теперь проверяют новый API;
общие изменяемые настройки из пункта 1.9 остаются задачей фазы 6.
