# 3.8. Именованные параметры проекции и допустимые значения

Пункт **3.8** [плана рефакторинга](../REFACTORING_PLAN.md) закрепляет контракт
параметров `PerspectiveCamera`, `OrthographicCamera`, `PerspectiveProjection`
и `OrthographicProjection`. Именованные аргументы и общая проверка уже введены
в 3.2–3.3; существующая реализация сохранена и дополнена проверками границ,
атомарности ошибок и восстановления после них.

Публичный импорт `package:chronosgl/camera.dart` работает без браузера.
Те же типы доступны через браузерный `package:chronosgl/chronosgl.dart`.

## Перспективная проекция

| Именованный параметр | Смысл | Значение по умолчанию | Ограничение |
| --- | --- | --- | --- |
| `fovYRadians` | Полный вертикальный угол обзора в радианах | `50 * pi / 180` | `0 < fovYRadians < pi` |
| `aspectRatio` | Ширина / высота | `1` | `aspectRatio > 0` |
| `near` | Расстояние до ближней плоскости в единицах сцены | Обязательный | `near > 0` |
| `far` | Расстояние до дальней плоскости в единицах сцены | Обязательный | `far > near` |

Все четыре значения должны быть конечными. `NaN`, обе бесконечности,
нулевые (включая `-0.0`) FOV/aspect/near, угол `pi` и больше, совпадающие
или переставленные плоскости дают `ArgumentError`. В частности, `50`
не означает 50 градусов: угол нужно перевести в радианы. Бесконечный `far`
и reversed-Z не поддерживаются.

FOV не является горизонтальным или половинным углом. На расстоянии `d`
полувысота frustum равна `d * tan(fovYRadians / 2)`, полуширина —
`полувысота * aspectRatio`. Это одинаково работает для portrait и landscape.
Canvas, размер текстуры и контроллеры не участвуют в расчёте.

```dart
import 'dart:math' as math;
import 'package:chronosgl/camera.dart';

final camera = PerspectiveCamera(
  fovYRadians: 60 * math.pi / 180,
  aspectRatio: 16 / 9,
  near: 0.1,
  far: 1000,
);

// Изменить только aspect: остальные значения передать явно.
camera.setProjection(
  fovYRadians: camera.fovYRadians,
  aspectRatio: 3 / 4,
  near: camera.near,
  far: camera.far,
);
```

## Ортографическая проекция

Все шесть именованных параметров `left`, `right`, `bottom`, `top`, `near`,
`far` обязательны. Это конечные границы в единицах сцены с условиями
`left < right`, `bottom < top`, `near < far`.

`near` и `far` — знаковые расстояния: плоскости находятся при
`zView = -near` и `zView = -far`. Допустимы `near = 0`, `far = 0`, отрицательные
значения обоих параметров и объёмы, пересекающие начало координат. Например,
`near: -10, far: -1` задаёт плоскости при `zView = 10` и `zView = 1`.
Порядок `near < far` обязателен и для отрицательных значений.
`fovYRadians` и `aspectRatio` здесь не применяются; масштаб и пропорции
задаются явными границами без автоматического resize.

Для обеих проекций используются векторы-столбцы и OpenGL NDC:
ближняя плоскость переходит в глубину `-1`, дальняя — в `+1`.

## Представимость и атомарность

Проверка выполняется обычным кодом и не зависит от включения assertions.
После проверки диапазонов рассчитывается Float32-матрица. Все её коэффициенты
должны быть конечными; коэффициенты, определяющие невырожденность,
не должны обнулиться при округлении. Корректных неравенств недостаточно:
например, положительный aspect `1e-40` переполняет горизонтальный коэффициент,
а `1e46` обнуляет его. Оба значения отклоняются с `ArgumentError`.
Для ортографической проекции аналогично проверяются все три оси.
Произвольных прикладных ограничений вроде FOV не меньше одного градуса нет.
Точность остаётся ограниченной Float32; это не гарантия заданной погрешности
для любого отношения `far / near`.

Конструкторы камер и самостоятельных проекций применяют одну и ту же проверку.
`PerspectiveCamera.setProjection` требует все четыре параметра,
`OrthographicCamera.setProjection` — все шесть. Значения по умолчанию
используются только конструкторами, а не как неявный сброс при обновлении.

Камера сначала создаёт новую неизменяемую проекцию и только затем заменяет
ссылку. При ошибке сохраняются прежний объект `projection`, его параметры,
все матрицы и мировая поза. После отказа можно успешно применить допустимые
значения. Успешное обновление также сохраняет позу; снимки и другие камеры,
использующие старый объект проекции, не меняются.

Legacy `Perspective(Spatial, near, far)` и `Orthographic(...)` сохраняют API;
`Perspective.updateFov` по-прежнему принимает градусы. Правила новых типов
не меняют единицы старого метода. Адаптер новых камер к uniforms относится
к 3.9, контроллеры и resize — к фазе 4.

## Проверки

[`projection_parameters_test.dart`](../test/projection_parameters_test.dart)
добавлен в preset `all` и содержит семь математических тестов:
полный вертикальный FOV с разными aspect, независимые изменения каждого
параметра, допустимые малые/большие значения, знаковые clipping distances,
отклонение неверных значений через все три пути API, Float32 overflow/underflow
и сохранение состояния с последующим успешным обновлением.

Существующие [`camera_test.dart`](../test/camera_test.dart) и
[`projection_test.dart`](../test/projection_test.dart) проверяют значения
по умолчанию, строгий порядок плоскостей и границ, нечисловые значения,
владение снимками и совместное использование проекций.

```sh
dart test -p vm test/projection_parameters_test.dart
```

При изменениях браузерной интеграции или Wasm-компиляции запускайте этот же
файл на затронутой платформе с `-p golden_chrome` и, для Wasm, `-c dart2wasm`.
