# 3.3. Проекции отдельно от камеры, uniforms и браузера

Пункт **3.3** [плана рефакторинга](../REFACTORING_PLAN.md) выделяет `Projection`,
`PerspectiveProjection` и `OrthographicProjection`. Они доступны через
`package:chronosgl/camera.dart` на VM, JavaScript и Wasm и через общий браузерный
импорт `chronosgl.dart`. Файл `src/camera/projection.dart` зависит только от
`dart:math` и `vector_math`: камера, `UniformGroup`, WebGL и DOM ему не нужны.

## Контракт и владение

`Projection` задаёт отображение view → clip. `matrix` возвращает независимый
снимок `Matrix4`, а `copyMatrixInto(out)` полностью перезаписывает матрицу
вызывающего кода. Изменение любого результата не меняет проекцию. Пользовательские
реализации `Projection` должны соблюдать тот же неизменяемый контракт.

Две готовые реализации — `final`-классы с неизменяемыми параметрами и приватной
матрицей, вычисляемой при создании. Один объект можно передать нескольким
камерам или использовать при расчёте теней. Для других параметров создаётся
новая проекция; `update()`, `dispose()`, подписок и GPU-ресурсов нет.

| Тип | Параметры и ограничения |
| --- | --- |
| `PerspectiveProjection` | `fovYRadians` — полный вертикальный угол в радианах, по умолчанию `50 * pi / 180`; `aspectRatio` — ширина / высота, по умолчанию `1`; обязательные `near`, `far`; `0 < fovYRadians < pi`, `aspectRatio > 0`, `0 < near < far` |
| `OrthographicProjection` | Обязательные `left`, `right`, `bottom`, `top`, `near`, `far` в единицах сцены; `left < right`, `bottom < top`, `near < far`; нулевой и отрицательный `near` допустимы |

Все параметры должны быть конечными, матрица — конечной и невырожденной
в Float32. Неверные значения дают `ArgumentError`. Бесконечный `far` и reversed-Z
не поддерживаются. Проекция использует векторы-столбцы и OpenGL NDC:
`zView = -near` переходит в `-1`, `zView = -far` — в `+1` после деления на `w`.
Размер canvas или текстуры не меняет границы автоматически.

## Камеры

`PerspectiveCamera` и `OrthographicCamera` делегируют расчёт и проверку
параметров соответствующей проекции. Их существующие конструкторы, getters
параметров, `projectionMatrix` и `setProjection(...)` сохраняют контракт 3.2.
`setProjection` сначала создаёт новую проверенную проекцию, затем заменяет
ссылку: ошибка оставляет прежний объект, параметры, матрицу и позу камеры.

Новый getter `projection` возвращает текущий неизменяемый объект. Конструкторы
`PerspectiveCamera.fromProjection(projection, position: ..., rotation: ...)`
и `OrthographicCamera.fromProjection(...)` позволяют использовать готовую
проекцию. Поза каждой камеры независима; изменение параметров одной камеры
не меняет общий старый объект и другие камеры.

```dart
import 'package:chronosgl/camera.dart';
import 'package:vector_math/vector_math.dart' as vm;

final projection = PerspectiveProjection(
  aspectRatio: 16 / 9,
  near: 0.1,
  far: 1000,
);
final camera = PerspectiveCamera.fromProjection(
  projection,
  position: vm.Vector3(0, 0, 10),
);
camera.lookAt(vm.Vector3.zero());
final worldToClip = camera.viewProjectionMatrix;
```

## Расчёт теней

Ортографическая проекция подходит для направленного света, перспективная —
для прожектора. Независимая от камеры композиция имеет вид
`lightMatrix = projection.matrix * lightViewMatrix`. Bias к координатам текстуры
в эту матрицу не включается; shader и framebuffer остаются обязанностью рендера.

```dart
final shadowProjection = OrthographicProjection(
  left: -20,
  right: 20,
  bottom: -20,
  top: 20,
  near: -20,
  far: 20,
);
final lightView = vm.makeViewMatrix(
  vm.Vector3.zero(),
  vm.Vector3(1, -2, 3),
  vm.Vector3(0, 1, 0),
);
final lightMatrix = shadowProjection.matrix..multiply(lightView);
// В браузерном коде: shadowMap.compute(lightMatrix).
```

`DirectionalLight.extractShadowProjViewMatrix()` теперь использует
`OrthographicProjection`, сохраняя симметричные границы и signed depth
`[-dim, dim]`. `SpotLight.extractShadowProjViewMatrix()` использует
`PerspectiveProjection`, сохраняя aspect `1` и вертикальный FOV `2.1 * angle`
(полный угол конуса с прежним запасом). Выбор up и порядок `P * V` сохранены;
изменения направления, позиции и угла света учитываются при следующем вызове.
Неверные параметры проекции теперь дают `ArgumentError` при расчёте теней.
Legacy-методы по-прежнему возвращают свои переиспользуемые матрицы.

`ShadowMap.compute(Matrix4)` уже принимает готовую матрицу; изменение его API
не требуется. Старые `Perspective`/`Orthographic` как адаптеры uniforms и
браузерные resize-помощники сохраняют прежний API. `CameraUniforms` относится
к 3.9, дальнейшее разделение `ShadowMap` и визуализации — к фазе 6.

## Проверки

[`projection_test.dart`](../test/projection_test.dart) содержит 12 тестов:
самостоятельные проекции без камеры и браузера, границы frustum, signed depth,
неверные параметры, владение матрицами, композиция с видом света и совместное
использование проекции камерами с независимым обновлением.
[`projection_compatibility_test.dart`](../test/projection_compatibility_test.dart)
содержит 4 браузерных теста экспортов и существующего пути построения теней,
включая вертикальное направление света, изменение угла и ошибки параметров.
Оба файла включены в preset `all`; прежние 25 тестов камер остаются в нём.

```sh
dart analyze
dart test -P all
dart test -P all -p golden_chrome -c dart2wasm
```

Результаты на Dart 3.14.0: `dart analyze` — без замечаний; полный
VM/JavaScript-прогон — 394 теста, прогон с Wasm — 392 теста (preset также
выполняет VM-наборы; два legacy DOM-теста предназначены только для JavaScript).
Все 12 математических тестов проекций проходят на трёх платформах,
4 проверки совместимости — в JavaScript и Wasm. Rendering goldens совпадают
с существующими эталонами; изображения не обновлялись.
